### Управление компьютером жестами руки через обычную веб-камеру

</div>

**Phantom** превращает движения руки в управление курсором Windows. Проект отслеживает 21 точку кисти с помощью MediaPipe, сглаживает движение и передаёт команды мыши через PyAutoGUI.

## Возможности

- движение курсора указательным пальцем;
- клик сведением большого и среднего пальцев;
- прокрутка безымянным пальцем и мизинцем;
- переключение на следующее приложение сжатым кулаком;
- пауза и возобновление открытой ладонью;
- автоматическая пауза при потере руки;
- настраиваемые чувствительность, сглаживание и активная область;
- диагностическое окно камеры с точками, линиями и текущим состоянием;
- отдельное графическое приложение для запуска и настройки.

---

## Установка

Требуется Python 3 и веб-камера.

```bash
pip install opencv-python mediapipe pyautogui numpy
```

Файл модели `hand_landmarker.task` уже должен находиться рядом с программой. Если его нет, движок попробует скачать модель автоматически.

## Запуск

Графическое приложение:

```bash
python phantom.py
```

На Windows также можно открыть двойным нажатием:

```text
launch_phantom.pyw
```

Запуск движка напрямую без панели настроек:

```bash
python main.py
```

В панели Phantom нажмите **START**. Для завершения нажмите **STOP**. Если включено окно камеры, его также можно закрыть клавишей `Q`.

## Как пользоваться жестами

### 1. Движение курсора

Покажите камере руку и перемещайте **кончик указательного пальца**. Его положение внутри активной области камеры преобразуется в координаты экрана.

Движение проходит через два этапа сглаживания, поэтому небольшое дрожание пальца не должно передаваться курсору. Чтобы попасть в угол экрана, достаточно довести палец до соответствующей границы внутренней рамки, а не до самого края камеры.

### 2. Левый клик

Сведите вместе **большой и средний пальцы**, затем разведите их.

Клик подтверждается несколькими последовательными кадрами и имеет задержку между срабатываниями. Это защищает от случайных двойных кликов. Во время сведения движение курсора временно фиксируется.

Функцию можно полностью отключить параметром **Enable pinch click**.

### 3. Прокрутка страницы

Согните **указательный и средний пальцы**, а безымянный палец и мизинец используйте для движения:

- разгибание безымянного и мизинца — прокрутка вверх;
- сгибание безымянного и мизинца — прокрутка вниз;
- удержание пальцев без движения — остановка прокрутки.

Phantom измеряет изменение формы этих двух пальцев относительно костяшек. Поэтому двигать всю кисть вверх и вниз не требуется. В диагностическом окне отслеживаемые пальцы выделяются цветными линиями, а стрелка показывает направление.

### 4. Переключение приложения

Полностью сожмите руку в **кулак**. После короткого подтверждения Phantom выполнит `Alt + Tab` и переключит Windows на следующее приложение.

Одно сжатие вызывает только одно переключение. Перед повтором кулак необходимо раскрыть. Функцию можно отключить в настройках.

### 5. Пауза открытой ладонью

Покажите камере **полностью открытую ладонь** и удерживайте её заданное время. Управление будет поставлено на паузу. Повторное удержание открытой ладони возобновит работу.

После переключения действует защита от повторного срабатывания: сначала уберите жест, а затем покажите ладонь снова.

### 6. Автоматическая и экстренная пауза

Если рука отсутствует в кадре дольше значения **Auto-pause**, Phantom автоматически остановит управление. Самостоятельно оно не возобновится — для продолжения покажите открытую ладонь.

Экстренно остановить управление можно кнопкой **PAUSE/RESUME** или сочетанием `Ctrl + Shift + P`, пока окно Phantom активно.

### 7. Указательный палец вышел из кадра

Если кисть видна, но кончик указательного пальца касается края изображения, управление временно блокируется и появляется сообщение **SHOW INDEX FINGER**. Верните весь указательный палец в кадр.

## Настройки

### Pointer // Motion

| Настройка | Назначение |
|---|---|
| **Cursor responsiveness** | Скорость реакции курсора. Выше — быстрее, ниже — плавнее. |
| **Cursor smoothing** | Скорость следования отфильтрованной точки за пальцем. Малое значение сильнее подавляет дрожание. |
| **Active area margin** | Отступ внутренней рабочей области от краёв камеры. Больше значение уменьшает нужный размах руки. |
| **Scroll sensitivity** | Скорость прокрутки при движении пальцев. |
| **Scroll dead zone** | Минимальное движение пальцев, которое считается прокруткой. Увеличьте при случайном дрожании страницы. |
| **Open palm hold** | Сколько секунд удерживать открытую ладонь для паузы или продолжения. |
| **Gesture debounce** | Защитная задержка между переключениями паузы. |
| **Auto-pause** | Время без руки до автоматической паузы. Значение `0` отключает автопаузу. |

### System // Control

| Настройка | Назначение |
|---|---|
| **Camera index** | Номер используемой камеры. Обычно встроенная камера имеет индекс `0`. |
| **Enable pinch click** | Разрешает клик большим и средним пальцами. |
| **Fist gesture triggers Alt+Tab** | Разрешает переключение приложений кулаком. |
| **Show camera debug overlay** | Показывает изображение камеры, ориентиры кисти, активную область, FPS и статус жеста. |

**SAVE SETTINGS** записывает параметры в `phantom_config.json`. **RESET** возвращает стандартные значения в интерфейсе; после этого нажмите сохранение или запуск.

## Советы для точного распознавания

- Расположите камеру перед собой, а не сбоку.
- Используйте равномерное освещение без яркого окна за рукой.
- Держите всю кисть и кончики пальцев внутри кадра.
- Выберите фон, отличающийся по цвету от руки.
- Если курсор дрожит, уменьшите responsiveness или smoothing.
- Если страница прокручивается случайно, увеличьте scroll dead zone.
- Если до углов экрана трудно дотянуться, увеличьте active area margin.
- Сначала включите debug overlay и проверьте, правильно ли определяются суставы.

## Структура проекта

| Файл | Назначение |
|---|---|
| `phantom.py` | Графический интерфейс Phantom. |
| `launch_phantom.pyw` | Запуск приложения без консольного окна Windows. |
| `main.py` | Камера, распознавание жестов и управление системой. |
| `gesture_state.py` | Логика паузы, удержания жеста и автопаузы. |
| `phantom_config.py` | Модель, проверка и сохранение настроек. |
| `phantom_config.json` | Текущие пользовательские настройки. |
| `hand_landmarker.task` | Модель распознавания кисти MediaPipe. |
| `test_*.py` | Автоматические тесты жестов, состояний и конфигурации. |

## Проверка проекта

Тесты не запускают камеру и не выполняют реальные действия мышью:

```bash
python -m unittest discover -v
```

Проверка синтаксиса:

```bash
python -m py_compile main.py phantom.py phantom_config.py gesture_state.py
```

## Безопасность

Перед первым использованием закройте важные диалоги и несохранённые формы. Начните с включённого диагностического окна и невысокой чувствительности. Для мгновенной остановки используйте кнопку паузы, `Ctrl + Shift + P`, кнопку **STOP** или уберите руку до срабатывания автопаузы.
